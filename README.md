# DAP 문제은행

DAP(데이터아키텍처 준전문가) 대비 문제풀이 웹앱. 별도 서버 없이 브라우저에서만 동작하는 정적 페이지다.

## 사용

- 배포본: https://ikaros3.github.io/dap/
- 로컬: 이 폴더의 `index.html` 을 브라우저로 열면 된다.

## 구조

```
index.html      앱 본체 (HTML + CSS + JS 단일 파일)
data/           문제은행 데이터. 자세한 내용은 data/README.md 참고
```

## 진도 저장

풀이 진도는 브라우저 `localStorage` 에 자동 저장된다.
설정 화면의 **진도 저장** 버튼을 누르면 `dap-progress.json` 파일로 내보낼 수 있고,
**진도 파일 불러오기** 로 되돌릴 수 있다.

Chrome/Edge 에서 HTTPS 로 접속한 경우(위 배포본 주소) 처음 한 번 저장 위치를 지정하면
이후에는 같은 파일에 바로 덮어쓴다. File System Access API 를 지원하지 않는
브라우저(Firefox/Safari, 모바일)에서는 매번 다운로드 폴더에 저장된다.

## 여러 기기에서 같이 쓰기 (진도 동기화)

PC와 폰의 진도를 하나로 합치려면 설정 화면의 **진도 동기화**를 쓴다.
비공개 Gist 하나를 원본으로 두고, 기기마다 가져와 병합한 뒤 다시 올리는 방식이다.

1. https://github.com/settings/tokens 에서 classic 토큰을 만들고 **`gist` 권한만** 체크한다.
   (만료일을 지정해 두는 것을 권한다.)
2. 첫 기기: 설정 > 진도 동기화에 토큰을 넣고 **Gist ID 는 비운 채** [연결] 을 누른다.
   비공개 Gist 가 새로 만들어지고 ID 가 표시된다.
3. 다른 기기: 같은 토큰과 위에서 나온 Gist ID 를 넣고 [연결] 을 누른다.

연결한 뒤에는 앱을 열 때, 그리고 기록이 바뀌고 20초 뒤에 자동으로 동기화된다.
탭을 덮거나 앱을 벗어날 때도 대기 중인 변경분을 바로 올린다.

병합은 `mergeState()` 규칙을 따른다 — 문항별로 마지막 풀이 시각이 최신인 쪽을 채택하고,
북마크·오답노트·모의고사 이력은 합집합을 취한다. 문제를 풀고 있는 중이라면
그 세션만은 화면이 튀지 않도록 로컬 상태를 유지한다.

> 토큰은 해당 브라우저의 `localStorage` 에만 저장되며 진도 파일에는 포함되지 않는다.
> 공용 PC 에서는 연결하지 말 것. 연결 해제 버튼으로 토큰을 지울 수 있다.

동기화를 쓰지 않아도 **진도 저장 / 진도 파일 불러오기** 로 수동 이전은 그대로 가능하다.
