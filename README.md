# DAPath

DAP(데이터아키텍처 준전문가) 대비 학습 웹앱. 별도 서버 없이 브라우저에서만 동작하는 정적 페이지다.

화면은 카테고리 넷으로 나뉜다. 웹은 맨 위 탭, 모바일은 아래쪽 탭바로 오간다.
기본 이론은 사이드바 위(모바일은 상단바 아래)에서 2020 · 2013 · 요약 슬라이드를 고른다.

- **동영상 강의** — 과목별 강의 영상 31편(I~V). 영상은 저장소에 두지 않고 구글 드라이브(「DAP/2. DAP 영상 강의」)에 있으며,
  드라이브 미리보기 플레이어로 재생한다. 파일이 소유자 전용이라 그 구글 계정으로 로그인한 브라우저에서만 나온다
  (안 나오면 [드라이브에서 열기]). 강의마다 과목 강의자료 PDF·이론·문제로 건너가고, [봤음 표시]는 진도와 함께 동기화된다
  PC 의 Chrome/Edge 에서는 개요의 [강의 폴더 연결]로 그 폴더(구글 드라이브 데스크톱의 G:\내 드라이브\DAP\2. DAP 영상 강의)를
  골라 두면 앱이 직접 재생한다 — 1.1·1.15배속 등 속도 버튼을 쓰고, 강의마다 보던 위치에서 이어 본다(그 기기에만 적용)
- **요약 슬라이드**(기본 이론) — 준비 중
- **문제은행** — 문항 풀이·실전 모의고사·오답노트·복습
- **2020 Edition** — 교재 요약본(2020 Edition)의 이론을 과목 → 장 → 절로 정리한 읽기 화면. 여섯 과목 모두 있다.
  절마다 그 절의 문항을 바로 풀 수 있고, 문항 해설의 [2020 Edition 에서 보기]는 해당 소제목으로 건너뛴다
- **2013 Edition** — 데이터아키텍처 준전문가 가이드(교재) 본문을 개조식으로 정리한 읽기 화면.
  가이드에 없는 V·VI 는 2013 워드 요약(.doc)으로 채웠고, I~IV 에 워드 요약에서 보탠 내용은 「✎워드」 배지로 표시한다
- **실기** — Data Modeling(실기) 실습문제 30개(기초 → 특급). 요구 사항 지문을 읽고 직접 모델을 그려 본 뒤
  모범 답안 ERD 와 비교한다. [답안 먼저 가리기]를 켜 두면 답안을 가려 둔 채 문제가 열린다.
  ERD 를 누르면 화면 가득 크게 본다(휠·두 손가락 확대, 끌어서 이동, 두 번 눌러 맞춤). [풀어 봄] 표시는 진도와 함께 동기화된다

두 Edition 모두 **형광펜**을 쓸 수 있다. 본문 글자를 선택하면 색 막대(중요·헷갈림·꼭 암기)가 뜨고,
칠한 곳을 누르면 색·메모를 고친다. [가리기]는 칠한 글자를 가려 암기 확인용으로, [형광만 보기]는 칠한 줄만 남긴다.
레일의 **형광펜 모아보기**에서 판별로 모아 보고 그 자리로 건너뛸 수 있다. 형광펜은 진도와 함께 저장·동기화된다.

## 사용

- 배포본: https://ikaros3.github.io/dap/
- 로컬: 이 폴더의 `index.html` 을 브라우저로 열면 된다.

## 구조

```
index.html      앱 본체 (HTML + CSS + JS 단일 파일)
data/           문제은행 데이터. 자세한 내용은 data/README.md 참고
data/notes/     내용정리 데이터 — 2020 판(과목별 파일 + img/), 2013 판(2013/ + img2013/)
data/dm/        실기 데이터 — 문제 30개(dm.js) + ERD 그림(img/)
data/video/     동영상 강의 목록 — 과목·강의·재생 시간·구글 드라이브 파일 id(video.js). 영상을 바꾸면 이 파일만 고친다
```

## 진도 저장

풀이 진도는 브라우저 `localStorage` 에 자동 저장된다.
설정 화면의 **진도 저장** 버튼을 누르면 `dap-progress.json` 파일로 내보낼 수 있고,
**진도 파일 불러오기** 로 되돌릴 수 있다.

Chrome/Edge 에서 HTTPS 로 접속한 경우(위 배포본 주소) 처음 한 번 저장 위치를 지정하면
이후에는 같은 파일에 바로 덮어쓴다. File System Access API 를 지원하지 않는
브라우저(Firefox/Safari, 모바일)에서는 매번 다운로드 폴더에 저장된다.

## 여러 기기에서 같이 쓰기 (진도 동기화)

PC와 폰의 진도를 하나로 합치려면 설정 화면의 **진도 동기화**를 쓴다.
비공개 Gist 하나를 원본으로 두고, 기기마다 가져와 병합한 뒤 다시 올리는 방식이다.

1. https://github.com/settings/tokens 에서 classic 토큰을 만들고 **`gist` 권한만** 체크한다.
   (만료일을 지정해 두는 것을 권한다.)
2. 첫 기기: 설정 > 진도 동기화에 토큰을 넣고 **Gist ID 는 비운 채** [연결] 을 누른다.
   비공개 Gist 가 새로 만들어지고 ID 가 표시된다.
3. 다른 기기: 같은 토큰과 위에서 나온 Gist ID 를 넣고 [연결] 을 누른다.

연결한 뒤에는 앱을 열 때, 그리고 기록이 바뀌고 20초 뒤에 자동으로 동기화된다.
탭을 덮거나 앱을 벗어날 때도 대기 중인 변경분을 바로 올린다.

병합은 `mergeState()` 규칙을 따른다 — 문항별로 마지막 풀이 시각이 최신인 쪽을 채택하고,
북마크·오답노트·모의고사 이력은 합집합을 취한다. 문제를 풀고 있는 중이라면
그 세션만은 화면이 튀지 않도록 로컬 상태를 유지한다.

> 토큰은 해당 브라우저의 `localStorage` 에만 저장되며 진도 파일에는 포함되지 않는다.
> 공용 PC 에서는 연결하지 말 것. 연결 해제 버튼으로 토큰을 지울 수 있다.

동기화를 쓰지 않아도 **진도 저장 / 진도 파일 불러오기** 로 수동 이전은 그대로 가능하다.
