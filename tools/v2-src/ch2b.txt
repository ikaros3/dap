| 신상품 입고 |  |  |  | C |  |

① '상품'을 생성하는 기본 프로세스가 둘이므로 기본 프로세스의 중복으로 보고 합성을 검토한다.
② '배송'은 생성만 되고 사용되는 곳이 없으므로 기본 프로세스의 누락으로 보고 해당 프로세스를 도출한다.
③ '재고 조회'는 정보 항목을 조회만 하므로 기본 프로세스가 아닐 수 있어 모듈을 검토한다.
④ '주문 접수'는 여러 정보 항목에 액션을 수행하므로 관련 정보 항목을 세분화한다.
A: ④
E: 정보 항목의 세분화는 하나의 정보 항목이 7개 이상의 기본 프로세스에서 사용될 때의 조치다. 기본 프로세스가 여러 액션을 수행한다면 정의된 프로세스가 너무 크다는 뜻이므로 프로세스를 추가 분해한다. 생성 프로세스가 둘 이상이면 중복으로 합성하고, 생성만 되고 쓰이지 않으면 누락된 프로세스를 도출하며, 조회만 하는 프로세스는 기본 프로세스가 아니므로 모듈을 검토한다.
